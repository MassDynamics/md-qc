# Security and confidential reports

## Security vulnerabilities

Please don't open a public issue for a security vulnerability. Report it
privately, either through GitHub's
[private vulnerability reporting](https://github.com/MassDynamics/md-qc/security/advisories/new)
or by email to engineering@massdynamics.com. We will acknowledge the report and
keep you updated while we fix it.

## Confidential bug reports

GitHub issues on this repository are public. If a report needs instrument
serial numbers, raw file names, logs, payloads or customer and site details,
email engineering@massdynamics.com, or use your private partner tracker if you
have one. Fixes are still made in this public repository.

## Supported versions

Fixes go into the latest release. Upgrade to it before reporting a problem
where you can.
